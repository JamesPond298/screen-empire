# Opportunity and progression update

## What was missing

The previous live build had no opportunity scheduler, contract state, Studio Experience, genre registry, production decision, or release-report model. News could only report production status, and the Business button was disabled.

## First playable delivery

This update connects paid work, original productions, decisions, experience, genre choices, catalog deals, Career guidance, and actionable News. All event, contract, license, payment, unlock, and migration states persist in the browser save.

The six first-release opportunities are local commercial, script assessment, fixed-term streaming offer, paid screening, returning-client commission, and catalog rediscovery. Advances are part of the displayed total, direct costs are quoted separately, and all payments retain their event ID.

## Save migration

Save version 3 becomes version 4. The previous JSON is copied to the backup key before migration. Each already released original grants 100 experience, corresponding genre choices are calculated once, and no retroactive cash is invented. Existing cash, projects, catalog entries, costs, and transactions remain intact.

## Still future work

Talent development, returning television casts and seasons, hybrid mastery, rivals, release-date competition, festivals, awards, expansion, and optional loans remain later complete releases.
